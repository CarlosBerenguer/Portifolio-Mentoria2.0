## **1 — Requisitos Técnicos**

* **Backend**: Node.js + Express + MySQL (driver oficial `mysql2`).
* **Frontend**: HTML5, CSS3, JavaScript puro + MaterializeCSS.
* **Autenticação**: JWT (JSON Web Token).
* **Upload de imagens**: multer (armazenar caminho no banco).
* **Manipulação de datas**: dayjs ou date-fns (para cálculo de idade em anos, meses e dias).
* **Máscaras**: biblioteca para telefone e CPF (ex.: cleave.js).
* **Documentação da API**: Swagger.
* **Banco de dados**: MySQL com chaves primárias, estrangeiras, `UNIQUE` em CPF e CRP, e índices onde necessário.

## **3 — Banco de Dados MySQL — Modelagem Completa**

A credenciais para acessar o banco de dados:
user: root
password: root

```sql
CREATE DATABASE psicologos_db;
USE psicologos_db;

CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    usuario VARCHAR(50) NOT NULL UNIQUE,
    senha VARCHAR(255) NOT NULL,
    nome_completo VARCHAR(100) NOT NULL,
    cpf VARCHAR(14) NOT NULL UNIQUE,
    crp VARCHAR(20) NOT NULL UNIQUE,
    data_nascimento DATE NOT NULL,
    email VARCHAR(100) NOT NULL,
    telefone VARCHAR(20),
    especialidade VARCHAR(100),
    endereco TEXT,
    foto VARCHAR(255),
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE pacientes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome_completo VARCHAR(100) NOT NULL,
    data_nascimento DATE NOT NULL,
    email VARCHAR(100),
    telefone VARCHAR(20),
    demanda TEXT,
    diagnostico TEXT,
    cpf VARCHAR(14),
    endereco TEXT,
    responsavel VARCHAR(100),
    foto VARCHAR(255),
    criado_em TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE evolucoes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    paciente_id INT NOT NULL,
    data_hora DATETIME DEFAULT CURRENT_TIMESTAMP,
    observacao TEXT NOT NULL,
    FOREIGN KEY (paciente_id) REFERENCES pacientes(id) ON DELETE CASCADE
);

CREATE INDEX idx_pacientes_nome ON pacientes(nome_completo);
CREATE INDEX idx_usuarios_nome ON usuarios(nome_completo);
```

### **4.2 Rotas Backend (API REST)**

**Autenticação**

```
POST /auth/login → valida usuário e senha, retorna token JWT.
POST /auth/forgot → recebe usuário, CPF, email e valida.
POST /auth/reset → recebe nova senha e atualiza no banco.
```

**Usuários**

```
POST /usuarios → cadastra novo usuário.
GET /usuarios/:id → retorna dados do usuário.
PUT /usuarios/:id → atualiza dados do usuário.
```

**Pacientes**

```
POST /pacientes → cadastra novo paciente.
GET /pacientes → retorna lista de pacientes.
GET /pacientes/:id → retorna dados detalhados do paciente.
PUT /pacientes/:id → atualiza dados do paciente.
DELETE /pacientes/:id → remove paciente e suas evoluções.
```

**Evoluções**

```
POST /evolucoes → adiciona evolução de um paciente.
GET /evolucoes/:paciente_id → lista evoluções de um paciente (ordem desc).
```

**Uploads**

```
POST /upload/foto-usuario → salva imagem de perfil.
POST /upload/foto-paciente → salva imagem do paciente.
```
